# Лабораторна робота №7

## Тема: Шаблонізація у Spring MVC з використанням FreeMarker та формування HTML-листів (Gmail SMTP)**

---

##  1. Мета роботи
Ознайомитися з принципами серверної шаблонізації у Spring MVC на основі шаблонізатора **FreeMarker**.
Навчитися створювати динамічні HTML-шаблони для e-mail повідомлень, використовувати змінні, колекції,
умовні конструкції та освоїти інтеграцію Spring Boot із SMTP Gmail через сервіс **JavaMailSender**.

---

##  2. Короткі теоретичні відомості
**FreeMarker** — це заснований на Java шаблонізатор, який генерує текстовий вихід
(HTML-сторінки, електронні листи тощо) на основі шаблонів і змінних даних.

### Роль у Spring MVC та відмінності від Thymeleaf
- **Синтаксис:** Thymeleaf використовує HTML-атрибути (Natural Templates),
  тоді як FreeMarker базується на власних директивах (`<#if>`, `<#list>`).
- **Гнучкість:** FreeMarker краще підходить для генерації складних текстових структур,
  зокрема e-mail повідомлень.
- **Контекст:** Thymeleaf тісно інтегрований з веб-контекстом,
  тоді як FreeMarker ефективний для автономної генерації тексту.

---

##  3. Структура реалізованого застосунку
Застосунок побудований за багатомодульною архітектурою:

- **core** — бізнес-логіка та доменні моделі  
- **persistence** — рівень доступу до даних  
- **web** — Spring MVC, шаблони та сервіси розсилки  

### Розташування ресурсів у модулі `web`
- `src/main/resources/templates/` — веб-сторінки Thymeleaf  
- `src/main/resources/mail-templates/` — HTML-шаблони FreeMarker (`.ftl`)  
- `src/main/resources/mail-templates/layout/` — header та footer  

---

## ✉️ 4. Опис сервісу надсилання листів
Реалізація поштової системи включає:

- **SMTP конфігурація:** Gmail SMTP (порт 587, TLS, App Password)
- **EmailTemplateProcessor:** завантаження та обробка `.ftl` шаблонів
- **MailService:** формування `MimeMessage` та відправка через `JavaMailSender`

---

##  5. Реалізація додаткових елементів (+20%)
У HTML-шаблоні листа реалізовано:

- логотип через raw-URL з GitHub
- кастомний footer **BookApp © 2026**
- умовний блок **«Раритетне видання!»** (рік < 2000)

##  7. Відповіді на питання

### 1. Як відбувається передавання даних у FreeMarker?
Дані передаються у вигляді `Map<String, Object>`. Під час рендерингу
FreeMarker підставляє значення у плейсхолдери `${}` та виконує директиви
умов і циклів.

### 2. Як забезпечується безпечна відправка пошти?
Використовується **STARTTLS** та автентифікація через **App Passwords**.
`JavaMailSender` спрощує роботу з SMTP та обробку помилок.

### 3. Повний цикл формування e-mail
1. Підготовка моделі даних  
2. Отримання `.ftl` шаблону  
3. Генерація HTML  
4. Створення `MimeMessage`  
5. Відправка через `mailSender.send()`
